# MoSDOT: Multi-Agent Coordination via Support-Preserving Distillation

![MoSDOT overview](https://alex6095.github.io/mosdot/assets/figures/teaser.gif)

## Overview

Better coordination starts with a better teacher: align source noise with joint-action modes, then distill into local one-step policies. MoSDOT uses semi-discrete optimal transport for cleaner teachers and support-preserving decentralized distillation.
